# 🎓 University Admission Helper

A comprehensive web platform for Bangladeshi students to manage university admissions — check eligibility, bookmark universities, apply for scholarships, and track their progress.

## ✨ Features

- 🔐 **Secure authentication** — bcrypt password hashing, session-based login
- 🎓 **Eligibility checker** — auto-matches students with universities based on SSC/HSC GPA and academic group
- 🏛️ **163 universities** — complete list of public and private universities in Bangladesh
- 💰 **Scholarship applications** — apply directly through the platform
- 🔖 **Bookmark system** — save favorite universities for later
- 📊 **Student dashboard** — track eligibility, bookmarks, and applications
- 🛡️ **Admin panel** — hidden, admin-only access to manage users and view applications
- 🌙 **Dark mode toggle**
- 📱 **Fully responsive** — works on mobile, tablet, and desktop
- 🎨 **Sky blue light theme** — modern, clean design
